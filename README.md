# react-code-push-test-1

A test repository for React + CodePush experimentation. This repo is currently a placeholder — content will be added as the project takes shape.

## About

This repository was created to experiment with React and Microsoft's CodePush for over-the-air (OTA) updates in mobile or web apps. CodePush lets you push updates to your React Native / React app without going through the app store review process.

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/girishlade111/react-code-push-test-1.git
   cd react-code-push-test-1
   ```
2. Add your project files and commit them.
